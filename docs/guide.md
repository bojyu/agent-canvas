# Agent Canvas 使用指南

[返回项目首页](../README.md)

本文涵盖画布操作、服务配置、任务管理与数据保存。首次启动请先阅读 [README 的快速开始](../README.md#快速开始)。

## 画布操作

### 节点与预设

从左侧节点库拖出节点，通过连接点传递文本或素材。图片、视频和文本框既能提供输入，也能接收上游结果。生成结果可以继续作为后续创作的参考。

| 节点 | 用途 |
| :--- | :--- |
| 图片 / 视频 | 导入参考素材、查看生成结果、下载文件 |
| 文本框 | 编写文本、接收提示词结果、向下游传递内容 |
| Skill | 选择内置或已注册的本机 Skill，连接到编辑改写节点 |
| 编辑改写 | 根据创作需求和参考素材编写提示词 |
| 编辑提示词 | 修改已有提示词，将结果写入连接的文本框 |
| 图片生成 / 视频生成 | 将最终提示词与参考素材提交给所选生成服务 |

预设库包含常规提示词、图片生成、视频生成三种起点。点击或拖动预设会添加已连接的节点和参考图片节点，不会自动提交任务。

### Skill

内置选项包括「不加载 Skill」、Seedance、Nano Banana、GPT Image 和真实感场景与模特图。内置选项仍需对应的本机 Skill 文件就绪；缺失时会提示，不会自动替换成其他规则。

- **不加载 Skill**：仅根据节点需求与参考素材处理，不读取或注入 Skill 文件。
- **Seedance**：支持图片和视频参考，可设置参考模式、时长与画幅。
- **Nano Banana / GPT Image**：共用本机 Image Skill，分别加载对应模型规则，仅接收图片参考。
- **真实感场景**：按办公室、居家办公、创意工作室、卧室和电竞房等分类读取参考规则，关注结构、透视、人物重心、接触、光影与材质。

在「管理 Skill」中输入本机目录或 `SKILL.md` 路径即可注册自定义 Skill。支持检索、刷新和移除注册；移除注册不会删除磁盘文件，内置选项不可移除。

真实感 Skill 默认查找项目同级目录 `真实感skill/photoreal_scene_model_skill/SKILL.md`，也可通过 `PHOTOREAL_SKILL_PATH` 指定。

切换 Skill、供应商、模型或思考强度时，不兼容的会话状态会被清除。思考强度选项以模型能力为准；图片与视频生成节点不加载提示词 Skill，也不提供思考强度设置。

### 素材与生成

图片节点支持文件选择、图片拖入和剪贴板粘贴。双击空白图片节点可打开文件选择器；选中单个图片节点后可用 `Ctrl/Cmd + V` 粘贴图片。悬停预览后，通过下载按钮保存文件。

图片生成最多连接 12 张参考图，可设置常用画幅与 1K / 2K / 4K 分辨率，实际选项由渠道和模型决定。提示词可直接编辑，也可连接上游文本框；接入上游后由上游内容同步。

视频生成提供以下模式，具体支持情况以节点内的渠道与模型选项为准：

| 模式 | 输入 |
| :--- | :--- |
| 文生视频 | 提示词 |
| 单图生视频 | 1 张图片 |
| 首尾帧 | 2 张图片 |
| 智能多帧 | 2–12 张图片 |
| 全能参考 | 最多 9 张图片与 3 段视频 |

图片与视频参考按 `@图片N`、`@视频N` 编号。点击已连接的引用标记可插入提示词。参考容量按单个生成节点的输入计算，不包含下游输出节点。

### 复制与群组

复制单个节点时保留内容与配置；复制多个节点或完整群组时，同时保留选中节点之间的内部连线。Agent 会话与运行时状态不会继承。按住 `Alt` 拖动可移动新副本，原节点及其原有连线保留在原位。

选中至少两个未编组节点可创建群组；也可同时选择一个群组和散节点，将它们加入该群组。节点拖入群组并达到重叠阈值时会高亮，松手加入并自动扩展外框。

群组可整体移动、缩放和重命名，不支持嵌套。移出成员或打散群组会保留节点位置和连线；删除群组会同时删除成员。保存与分享会保留群组关系，「整理」只调整未编组节点。

| 操作 | 快捷键 |
| :--- | :--- |
| 复制 / 粘贴节点 | `Ctrl/Cmd + C` / `Ctrl/Cmd + V` |
| 拖动复制 | `Alt` + 拖动 |
| 建立群组 / 加入群组 | `Ctrl/Cmd + G` |
| 将选中成员移出群组 | `Ctrl/Cmd + Shift + G` |
| 打散群组 | `Ctrl/Cmd + Backspace` |
| 撤销 | `Ctrl/Cmd + Z` |

### 多画布与分享

顶部「文件」提供新建、打开、重命名、自动命名、保存与另存为。标签切换前会保存当前改动；关闭标签不删除项目，重新启动会恢复上次打开的标签。

「另存为」复制当前画布及素材，保留原项目。「导出分享」生成 `.promptflow.json`，包含节点、连线、提示词和素材。导入分享文件会分配新 ID 并打开新标签，不覆盖现有画布。

分享文件上限为 **200 MB**，媒体以文件内容嵌入，素材较多时体积会相应增加。导入前会校验版本、节点类型、ID、坐标、媒体格式与连线引用。

### 主题与保存

顶部「主题」支持跟随系统、浅色和深色。主题偏好保存在当前浏览器，不写入画布或分享文件；不会改变媒体本身的色彩。界面动效适配系统的「减少动态效果」设置。

顶部「输出目录」可更改生成素材的保存位置，默认为 `.prompt-flow-data/outputs`。图片解码落盘，视频下载到本地，节点显示实际路径；写入失败会明确提示。

本地草稿按项目恢复，仅存轻量节点数据，不将图片与视频二进制写入 LocalStorage。旧版文本和媒体节点会在打开画布时迁移；缺少 Skill 或供应商字段的旧项目分别按 Seedance 和 Codex 兼容处理。

## 服务配置

### API 密钥

在顶部「API 密钥」中配置 OpenRouter、Google Gemini 与 Comfly。界面仅显示是否已配置，不回显真实密钥。输入留空表示保持原值，需点击「清除」并保存才会删除。

设置写入本机 `.env.local` 与当前桥接进程，保存后立即生效。手动修改 `.env.local` 后需重启服务。完整字段见 [`.env.example`](../.env.example)。

| 字段 | 用途 |
| :--- | :--- |
| `OPENROUTER_API_KEY` | OpenRouter 提示词、图片与视频 |
| `GEMINI_API_KEY` | Google Gemini 图片生成，也接受 `GOOGLE_API_KEY` |
| `COMFLY_API_KEY` | Comfly 通用渠道 |
| `COMFLY_LLM_API_KEY` | Comfly 提示词专用；为空时回退到通用 Key |
| `COMFLY_GPT_IMAGE_2_1K_API_KEY` | Comfly GPT Image 2 的 1K 输出 |
| `COMFLY_GPT_IMAGE_2_2K_API_KEY` | Comfly GPT Image 2 的 2K 输出 |
| `COMFLY_GPT_IMAGE_2_4K_API_KEY` | Comfly GPT Image 2 的 4K 输出 |

Comfly GPT Image 2 的分辨率专用 Key 互不回退，也不使用通用 Key。未配置的渠道会显示未就绪。

### Codex 与 OpenRouter

Codex 通道复用本机 `codex login` 登录状态，通过 `@openai/codex-sdk` 调用。OpenRouter 使用独立 API Key，经 `@openrouter/agent` 调用，按 OpenRouter 账户计费；仓库锁定该 SDK 为 `0.7.2`。

模型列表、思考强度与任务阶段随节点所选供应商更新。不同供应商的会话标识相互隔离。

### Grok Build

本机安装对应 CLI 后，先在终端完成登录：

```sh
grok login
```

本项目通过 ACP 与缓存的登录令牌接入，并从 `grok models` 读取可用模型。实现中禁用 API Key 回退；若本机配置包含 `model.api_key`、`model.env_key` 或外部认证命令，会拒绝执行。账户资格及可用额度以服务端实际返回为准。

执行使用隔离临时工作区，完成后清理临时登录副本、Skill 和素材上下文。

### Antigravity

本项目默认使用命令为 `agy` 的 Antigravity CLI。请先在终端完成 CLI 登录，再验证非交互调用：

```sh
agy
agy -p "Reply with exactly OK and nothing else."
```

Windows 可使用仓库提供的检查脚本：

```powershell
.\scripts\antigravity-verify.cmd
```

CLI 不在默认路径时，在 `.env.local` 设置 `ANTIGRAVITY_CLI`。重启后可访问 [本地模型状态](http://127.0.0.1:4317/models?provider=antigravity) 检查配置结果。

`ALLOW_GEMINI_CLI_FALLBACK=1` 可显式启用 Gemini CLI 回退，默认关闭。登录资格、订阅和配额以对应服务的实际状态为准。

### Seedance CLI 与视频参考

使用本机 Seedance 通道前，安装 `dreamina` 并完成 `dreamina login`。如命令不在 PATH 中，通过 `DREAMINA_CLI_PATH` 指定可执行文件。

项目会在提交前检查积分：低于 100 时阻止生成，低于 500 时要求再次点击确认。提交视频任务会消耗对应服务额度。

提示词改写涉及参考视频时，需要本机 `ffmpeg`，最多抽取 4 张关键帧发送给模型。视频生成渠道则可能接收原始参考视频，两种用途的数据传输方式不同。

## 任务与自动化

任务中心显示排队、检查输入、处理素材、供应商生成、写入输出及最终结果，附带供应商、模型与耗时。进度使用实际阶段，不估算百分比。

默认并行数为 2，可切换到 1 或 3。超出并行数的任务进入队列；同一输出节点不允许并发创建任务，避免互相覆盖。

- 排队或运行中的任务支持取消；排队取消不会调用模型。
- 已结束任务可按当前节点配置重跑，失败时可复制错误信息。
- 任务卡可定位来源节点或查看结果，右侧面板可以收起。
- 单次 Agent 处理超时为 10 分钟，超时后提示失败。
- 最近 20 条记录保存在 `.prompt-flow-data/tasks.json`；服务运行中退出时，未完成任务会在重启后标为中断失败。

任务进度通过本地事件流同步，断开时每 3 秒轮询兜底，连接时每 15 秒补充同步；旧状态不会覆盖已经推进的任务状态。

Codex 插件使用 `revision`、`expectedRevision` 与 `transactionId` 保护写入，先 dry-run 再原子提交。浏览器存在未保存修改时不会静默覆盖；后台更新可通过顶部提示手动载入。插件默认创建独立后台画布，也可明确指定已有画布。

目前自动化支持单个生成节点执行。完整 DAG 调度、依赖执行和成本预算见[插件规划](plans/agent-canvas-codex-plugin.md)。

## 数据与隐私

画布项目保存在 `.prompt-flow-data/projects`，生成文件默认保存在 `.prompt-flow-data/outputs`。本地桥接只监听 `127.0.0.1` 并校验网页来源。

调用外部模型时，所需内容会离开本机：

| 任务 | 发送内容 |
| :--- | :--- |
| 提示词改写 | 节点需求、所选 Skill 规则及参考图片；支持视频参考时发送抽取的关键帧 |
| 图片生成 | 最终提示词与已连接的参考图 |
| 视频生成 | 提示词及所需原始图片、视频参考；Seedance CLI 使用临时素材文件上传 |

API Key 用于服务认证，不写入画布、分享文件或提示词内容。分享会移除 Agent 会话标识，但仍包含提示词和素材本身。

Skill 按节点的明确选择加载；缺失时任务停止，不会隐式切换规则。「不加载 Skill」不读取、不复制也不注入 Skill。OpenRouter 按白名单读取参考文档；Grok Build 和 Antigravity 使用隔离工作区，临时上下文在执行完成后清理。

Comfly 提示词请求失败后不会自动换模型重试。其他额度与计费由所选供应商决定，本地运行画布本身不代表外部生成免费。
